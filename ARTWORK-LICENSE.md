## Definitions

- **Official package:** an extension package (`.vsix`) of Honeywood released by Honeywood, for example through the Visual Studio Marketplace or this repository's releases, exactly as released.
- **Build:** any package or set of files produced from this repository's source by anyone other than Honeywood. That includes a rebuild of unchanged source. A build is not the official package.
